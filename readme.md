### Mô tả
Ứng dụng này là một hệ thống quản lý khóa học dành cho trung tâm tiếng Anh, hỗ trợ các vai trò Admin, Teacher, Student quản lý khóa học, bài giảng, thông báo và hồ sơ người dùng. Mục tiêu của đồ án là xây dựng ứng dụng di động Android hoàn chỉnh, kết nối với API backend để quản lý dữ liệu thực tế.
